## 1. Le service

SilenceWatch surveille des tâches planifiées (cron, workers, jobs) à partir de signaux, des appels HTTP qu’elles envoient quand elles s’exécutent. Quand un signal n’arrive pas à temps, le service ouvre un incident et envoie une alerte sur les canaux que vous avez configurés (e-mail, webhook, Slack, Microsoft Teams, Discord).
